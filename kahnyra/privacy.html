Privacy Policy

Application: Kahnyra · Last updated: 22 November 2026

1. Who we are

Kahnyra is a private automation application operated by the owner of the Kahnyra YouTube channel. It is used only to manage that channel and is not offered to other users.

2. Google user data we access

With the owner's permission (Google OAuth), the application accesses only the owner's own Google account data:

  • YouTube Data API v3 (scopes youtube.upload, youtube.force-ssl): upload videos, set titles, descriptions, tags, captions, localizations and playlists, and post comments on the owner's own channel.
  • YouTube Analytics API (scope yt-analytics.readonly): read view counts, watch time and similar statistics for the owner's own videos.
  • Google Drive API (scope drive): create, read, move and delete video, music and log files inside the owner's own Kahnyra folder.

3. How we use the data

The data is used only to publish and improve the owner's own videos (for example, to decide which topics perform best). It is not used for advertising, not sold, not shared with third parties, and not used to train AI models.

4. Storage and security

OAuth tokens are stored encrypted as GitHub Actions Secrets in a private repository and are never written to logs. Statistics reports are stored in the same private repository. Video files are stored in the owner's Google Drive and are deleted automatically after they have been uploaded to YouTube.

5. Limited Use

Kahnyra's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. YouTube API Services

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

7. Revoking access and deleting data

Access can be revoked at any time at Google Account → Third-party connections or via the Google security settings page. After revocation the application can no longer access any data, and stored statistics can be deleted on request within 30 days.

8. Viewers

The application does not collect personal data from people who watch Kahnyra videos. YouTube itself may collect data under its own policies.

9. Changes and contact

Changes to this policy will be published on this page. For questions, contact the channel owner through the Kahnyra YouTube channel.
